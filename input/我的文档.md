# 我的文档标题 (在这里写你的内容)

把你要转成 Word 的内容写在这个 `input/` 目录下的 `.md` 文件里。
运行脚本后，生成的 Word 会出现在 `output/` 目录。

## 1. 一个小节

写一段正文。支持 Markdown 这些语法：

- **加粗**、`行内代码`
- 列表（这条就是）
- 表格、插图、代码块

### 1.1 子标题

支持多级标题：`#` 一级，`##` 二级，`###` 三级…… 导出后就是 Word 的标题层级。

| 功能 | 写法 |
| --- | --- |
| 标题 | `#` `##` `###` |
| 加粗 | `**文字**` |
| 列表 | `- 项目` 或 `1. 项目` |
| 图片 | `![](图片.png)` |
| 代码块 | ```` ```c ```` |

## 2. 怎么生成 Word

```bash
# 本目录下运行(或用下方"最佳使用方式")
python scripts/md2docx.py input/我的文档.md output/我的文档.docx
```

> 建议直接把 `input/` 下的 md 文件名写进命令，生成的 docx 会在 `output/` 里。
